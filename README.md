# توقيعي — استخراج التوقيع من PDF

واجهة Streamlit عربية: رفع PDF، اختيار صفحة (الأخيرة افتراضيًا)، تحديد التوقيع بالماوس، معاينة وتنزيل PNG شفاف. تدعم الملفات المحمية بكلمة مرور. لا تستخدم API أو توليد صور؛ تعالج بكسلات الحبر مباشرة.

## التشغيل

يتطلب Python 3.10 أو أحدث. افتح الطرفية داخل هذا المجلد:

```powershell
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python -m streamlit run app.py
```

على macOS/Linux استبدل `.venv\Scripts\python` بـ `.venv/bin/python`.

افتح العنوان الذي يظهر في الطرفية، وعادة يكون http://localhost:8501.

## الاستخدام

1. ارفع PDF حتى 30 ميجابايت.
2. اختر الصفحة، ثم اسحب مستطيل التحديد ليحيط بالتوقيع دون الاسم أو التاريخ.
3. ارفع حساسية الاحتفاظ بالحبر إذا كان التوقيع باهتًا، أو اخفضها لإزالة ظلال الورق.
4. اختر الأسود أو الاحتفاظ بلون الحبر، ثم نزّل PNG الشفاف.

المربعات الرمادية تظهر في المعاينة فقط. البرنامج لا يكتشف التوقيع تلقائيًا ولا يزيل نصوصًا متداخلة معه. يناسب الحبر الداكن على خلفية فاتحة. الخلفيات الملونة أو الممسوحة بضوضاء شديدة قد تحتاج ضبط الحساسية. إخراج الصفحات محدود إلى 3600 بكسل لأطول ضلع لتقليل استهلاك الذاكرة.

الملفات تعالج في ذاكرة خادم Streamlit ولا تحفظ إلى القرص بواسطة التطبيق. تشغيله على جهازك يبقي المعالجة محلية؛ نشره على خادم ينقل الملفات إلى ذلك الخادم. لا توجد مفاتيح API مطلوبة.
